# Changelog

## 1.0.4

Структура репозитория по требованиям Маркета дополнений.

- Все файлы модуля хранятся в его каталогах: `modules/gree`, `templates/gree`,
  `img/modules/gree.png`, `scripts/cycle_gree.php`. `CHANGELOG.md`, `LICENSE` и
  скриншоты перенесены в `modules/gree/`.
- Из корня репозитория убраны `.gitignore`, `build-package.sh` и `install-gree.sh`.
  При установке из Маркета содержимое корня копируется в корень MajorDoMo:
  `.gitignore` и `LICENSE` перезаписывали одноимённые файлы системы.
- Пакет `gree.tgz` для релиза собирается из репозитория без отдельного скрипта.

## 1.0.3

Привязка к устройству «Кондиционер» MajorDoMo.

- При сохранении новой или изменённой привязки текущее значение сразу передаётся в
  свойство объекта. Раньше значение уходило в объект только при следующем изменении
  на кондиционере, и после привязки объект мог долго показывать старые данные.
- Режим и скорость вентилятора переводятся в значения устройства «Кондиционер», если
  привязка сделана к свойствам `thermostat` и `fanSpeed`: режим `0`–`4` ↔ `auto`,
  `cool`, `dry`, `fan_only`, `heat`; скорость `0` ↔ `auto`, `1` ↔ `low`,
  `2`–`4` → `medium` (обратно `3`), `5` ↔ `high`. Управление с карточки устройства,
  голосом и из сценариев работает в обе стороны.
- Неизвестное значение режима или скорости из объекта (например, опечатка в сценарии)
  не отправляется на кондиционер: раньше оно превратилось бы в режим «Авто».

## 1.0.2

Подготовка к публикации в Маркете дополнений.

- При удалении модуля снимаются привязки свойств объектов к GREE: раньше удалялись
  только таблицы, а у объектов оставались ссылки на несуществующий модуль.
- Версия в ссылках на `gree.css` и `gree.js` теперь совпадает с версией модуля:
  после обновления браузер загружает новые стили и скрипты, а не берёт старые из кэша.
- Добавлена лицензия MIT.

## 1.0.1

Оптимизация.

- Недоступный кондиционер больше не задерживает опрос остальных на 10 секунд:
  таймаут ответа 2 секунды, повторный широковещательный запрос (на случай смены
  IP) для одного блока не чаще раза в 5 минут.
- Результат опроса записывается одним чтением из базы вместо отдельного запроса
  на каждое свойство; в базу и в объекты уходят только изменившиеся значения.
- Поиск в сети получает ключи всех найденных кондиционеров параллельно: не
  дольше 6 секунд при любом количестве блоков.
- Цикл опроса не обращается к базе для интервалов, которые ни у одного
  кондиционера не выбраны.
- Состояние для интерфейса читается одним запросом для всех устройств.

## 1.0.0

Первый выпуск.

- Кондиционеры Gree (протоколы v1 AES-ECB и v2 AES-GCM) и Cooper&Hunter Smart Wi-Fi.
- Поиск в сети, получение ключа устройства, автоопределение версии протокола.
- Пульт в панели управления, список устройств с быстрым управлением.
- Привязка свойств к объектам MajorDoMo, фоновый опрос `cycle_gree`.
- Установка через Маркет дополнений (`gree.tgz`) или вручную.
- PHP 7.0 – 8.4.
